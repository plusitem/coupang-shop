상품 등록

이미지를 올리고 카테고리·상품명·가격·링크를 입력해 등록하면 목록에 쌓입니다. 등록이 끝나면 아래에서 products.csv를 내려받아 coupang-shop.html과 같은 폴더에 덮어쓰면 됩니다.

새 상품 등록

이미지를 1장 선택하면 정지 이미지로, 2장 이상 선택하면 움직이는 GIF로 등록됩니다

GitHub 자동 저장 설정

한 번만 입력해두면, 등록할 때마다 GitHub 저장소의 products.csv를 자동으로 갱신해서 고객 페이지에 바로 반영합니다.

방문 통계

구글 애널리틱스(GA4)로 고객 페이지의 방문 횟수와 평균 체류 시간을 확인할 수 있습니다.

방문 통계 보러가기 (analytics.google.com)

보고서 > 실시간 에서 지금 접속 중인 방문자 수를, 보고서 > 참여도 > 개요 에서 평균 참여 시간(체류 시간)을 확인하실 수 있습니다.
